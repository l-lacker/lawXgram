# patches/

Generated by `patchset export` — never edit `*.patch` files by hand. Change the stock
code in `worktree/`, fold it into a patch (`patchset new` / `patchset fixup`), then export.

| Group | Use |
| --- | --- |
| `misc` | build, branding, infrastructure |
| `hooks` | shared extension points used by three or more features; no effect on their own |
| `feature` | a contained Neogram feature or customization |
| `debloat` | hiding or disabling stock behaviour, normally behind a setting |
| `bugfix` | a fix for an upstream bug, one fix per patch |
